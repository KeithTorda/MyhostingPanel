# PHCrafter Custom Hosting Setup

This repository contains the custom modifications for the PhCrafter Pterodactyl Hosting Panel.

## Features
- **Custom Version Changer**: Dynamic Minecraft versions for Paper, Purpur, Bedrock, and PocketMine.
- **Auto Plugin Downloader**: Integrated Hangar API downloader.
- **Premium Design**: Custom React components for a professional look.
- **Multi-Node Support**: Automated downloads across multiple VPS nodes.

## How to Install
1. Install a fresh Pterodactyl Panel.
2. Clone this repo.
3. Run \ash install.sh\.
